# Dataset Instructions

## C4_200M.tsv-00004-of-00010

The raw dataset file is approximately 4.60 GB and is not included in this
repository because it exceeds GitHub's file size limits.

Dataset source:
https://www.kaggle.com/datasets/dariocioni/c4200m

### Setup

1. Download `C4_200M.tsv-00004-of-00010` from the dataset source.

2. Create the following directory if it does not already exist: 
        
        data/raw/

3. Place the downloaded file in:

    data/raw/C4_200M.tsv-00004-of-00010

Expected structure:

data/
└── raw/
    └── C4_200M.tsv-00004-of-00010

The preprocessing and training scripts assume this exact filename and path.
